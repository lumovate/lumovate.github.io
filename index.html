ThesisThese理念
For fifty years software has reached hardware through an operating system, a layer built for people at keyboards. When the operator is an agent, that layer may no longer be needed: the agent can drive the hardware itself. Hardware will change with it, designed less for general programs and more for running neural networks. We think this is where computing is heading, and we test it on real machines.
Seit fünfzig Jahren erreicht Software die Hardware über ein Betriebssystem, eine Schicht, die für Menschen an Tastaturen gebaut wurde. Wenn ein Agent die Maschine bedient, wird diese Schicht vielleicht überflüssig: Der Agent kann die Hardware selbst steuern. Die Hardware wird sich mitverändern, weniger für allgemeine Programme gebaut, mehr für neuronale Netze. Wir halten das für die Richtung der Informatik und prüfen es an echten Maschinen.
五十年来，软件都要经过操作系统才能触及硬件，而操作系统是为坐在键盘前的人设计的中间层。当操作者变成 Agent，这一层也许不再必要：Agent 可以直接操作硬件。硬件也会随之改变，不再为通用程序而造，而是专为运行神经网络而设计。我们认为这是计算的方向，并在真实的机器上验证它。

Ein kompakter Hardware-Befehlssatz über UDP (CPUID, PCI-Scan, Port-I/O, Speicher, Uhr; Port-Schreibzugriffe brauchen ein Bestätigungsbyte), Netzwerk-Boot, eine 1024×768-Konsole und ein Chat-Terminal, das Claude beantwortet.
